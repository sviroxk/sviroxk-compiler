# Changelog SC

Формат релизов — Semantic Versioning. До `1.0.0` язык имеет статус экспериментального; совместимость публичного синтаксиса и ABI не гарантируется без отдельной пометки в release notes. Legacy-синтаксис не объявляется deprecated без отдельной реализации warning.

## [0.3.0] — текущая разработка

- Обновлены README и полный канонический текст Apache License 2.0; fixtures перенесены в tests/examples, локальная .vscode удалена и игнорируется. Синтаксис и поведение SC не менялись.

- Добавлен `defer` для обычных операций и вызовов: LIFO при выходе из области, раннем return, break/continue. Переходы управления и объявления внутри defer временно отклоняются; `drop` не добавлен.

- Перенесён шаг 4б PR22: параметры структур `Name value` по значению и запись вложенного поля `Inner field`. Изменение value-полей копии не меняет аргумент вызывающего кода.

- Исправлен verifier error в `print(v.pop())`: нулевой результат для пустого dynamic array теперь приходит в PHI из правильного блока. Существующий контракт `pop()` (последний элемент или ноль) не менялся.

- Добавлены 10 memory-safety sanitizer-проверок для heap pointers, динамических массивов и файлов; 3 корректных heap lifecycle cases проверяют утечки. Синтаксис и модель памяти языка не менялись.

- Убрано глобальное состояние parser; копии узлов AST больше не оставляют висячие ссылки после уничтожения исходного дерева. Синтаксис языка не изменён.

- Добавлены short-circuit `&&`/`||`, bounds checks статических массивов, source-based math helpers.
- Семантическая проверка фиксированных scalar types, numeric literals и явных numeric casts.
- Текущие известные ограничения перечисляются в `docs/spec.md` (раздел 17).
