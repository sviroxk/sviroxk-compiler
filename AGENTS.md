# AGENTS.md — правила для ИИ-агентов и людей

Этот файл главнее остальных документов, когда речь о процессе. Читать целиком перед работой.

## Сборка и тесты

```bash
CXX=clang++ CXXFLAGS="-Wall -Wextra -Werror" ./build.sh   # нужен только llvm-config (LLVM 18)
./test.sh                                                  # все тесты; код 0 = всё прошло
./test-conformance.sh
```

- Сборка остаётся `./build.sh` + `llvm-config`, без CMake и новых зависимостей: компилятор собирают в Termux на телефоне.
- Эталонная версия LLVM — 18 (так же в CI).
- Каждый ручной запуск компилятора — только с таймаутом: `timeout 10 ./sc file.svx > out.ll`. Зависание = баг компилятора, а не повод ждать дольше.
- Запуск программы: `./sc file.svx > out.ll && lli out.ll`.

## Как работать

1. Одна задача = новая ветка от свежего `main` = один PR. Ветка `feat/…`, `fix/…`, `chore/…`.
2. PR до ~300 изменённых строк. Больше — разбить.
3. В описании PR два раздела: **Что сделано** и **Как проверено** (команды и реальные числа: сколько тестов, что упало до правки).
4. Не мержить `main` в старую ветку и не переиспользовать ветку после слияния её PR. Нужна новая работа — новая ветка от `main`.
5. В `main` напрямую не пушить. Сливает PR только владелец.
6. Каждый исправленный баг = тест, который падал до исправления и проходит после.
7. Каждая новая возможность = положительный тест с проверкой вывода и отрицательный тест с проверкой текста ошибки.
8. Готовность считается по тестам, а не по процентам. Не писать «100%», «всё готово» без теста, который это показывает.
9. Если тест упирается в баг вне задачи — не чинить попутно, записать в описание PR.

## Каким документам верить

- Правда — это код и `test.sh`. Журнал работы — `docs/progress.md` (дописывать в конец, коротко).
- `README.md`, `STATUS.md`, `docs/language.md`, `docs/roadmap.md`, `docs/core-audit.md` местами расходятся с кодом (в `core-audit.md` есть синтаксис, которого нет в компиляторе). Считать их устаревшими, пока не появится `docs/spec.md` — единая спецификация языка.
- Перед тем как опираться на пример синтаксиса из документа, скомпилируй его.
