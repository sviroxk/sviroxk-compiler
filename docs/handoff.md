## Решения владельца (не пересматривать молча)

- `docs/decisions.md` D-007 (2026-11-12): `%` для дробных как в C; `input_str` читает всю строку; `SC runtime error` в stderr; использование после `close` и `return &локальная` — ошибки компиляции; вложенность 256; без `std::format`; LLVM 23.1.5 основная, 18–22 через CI-матрицу; C++20.
- Предел длины выражения — «столько сколько можно» (цель — снять предел совсем).
- Одно слово на одно действие; точные имена типов (`i32`…) основные, короткие (`int`…) — алиасы.
- Память «как в Rust и C++»: автоосвобождение и проверки владения плюс ручной режим; без сборщика мусора.
- Сборка — `./build.sh` + `llvm-config`, без CMake и новых зависимостей.
- Библиотеки: вызов C-функций (`extern`) + линковка, C++ через обёртку `extern "C"`, имена модулей для своих библиотек; новые библиотеки не писать; синтаксис — только после ответа владельца на дизайн-документ.
- Правило кредитов (AGENTS.md): при балансе ≤ 1000 — переписать это письмо целиком отдельным PR, без открытых PR и расхождения dev/main.
