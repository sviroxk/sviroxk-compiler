# Спецификация языка SC

Это единственное описание языка. Оно составлено по поведению компилятора `0.3.0`
и проверяется тестами: каждый пример ниже `test.sh` извлекает, компилирует и
запускает, а вывод сравнивает с блоком «вывод». Если документ расходится с кодом,
ошибка в документе, и тест это покажет.

Соглашение для примеров:
- блок `sc` — программа, за ним блок `text` с точным выводом;
- блок `stdin` между ними — то, что программа получает на вход;
- блок `sc-error` — программа, которая не должна компилироваться; блок `text`
  после неё содержит часть сообщения об ошибке.

## 1. Программа

Файл `.svx` — это последовательность объявлений и операторов. Код верхнего
уровня выполняется сверху вниз, отдельная функция `main` не нужна (имя `main`
занято). Комментарии: `// до конца строки`. Оператор заканчивается `;`.

```sc
// вывод
print("Привет, мир!");
print(42);
```
```text
Привет, мир!
42
```

Сборка и запуск: `./sc файл.svx > файл.ll`, затем `lli файл.ll` или `llc` и `clang`.
Код выхода компилятора: 0 — успех, 1 — синтаксическая ошибка, 2 — семантическая,
3 — внутренняя ошибка компилятора. Ошибка выполнения печатает
`SC runtime error: <что> at line L, column C` и завершает программу с кодом 1.

## 2. Типы

| Тип | Короткое имя | Что это |
|---|---|---|
| `i8` `i16` `i32` `i64` | `short` = i16, `int` = i32, `long` = i64 | знаковые целые |
| `u8` `u16` `u32` `u64` | `byte` = u8, `ushort` = u16, `uint` = u32, `ulong` = u64 | беззнаковые целые |
| `f32` `f64` | `float` = f32, `double` = f64 | числа с плавающей точкой |
| `bool` | | `true` / `false` |
| `char` | | символ `'a'`, в арифметике ведёт себя как `u8` |
| `str` | `string` | строка |
| `ptr` | | указатель или динамический массив |
| `file` | | открытый файл |
| `tip Имя` | | структура |
| `void` | | «нет значения», только тип результата функции |

Точные имена (`i32`, `f64` …) — основные, короткие — их алиасы.
Целые литералы по умолчанию имеют тип `i32`, дробные — `f64`.
Литералы: `42`, `0x2A`, `0b101010`, `1_000`, `1.5`, `2e3`, `'a'`, `"текст"`.

## 3. Переменные

```sc
int a = 1;          // тип и значение
let b = 2;          // тип выводится из значения
let c: i64 = 3;     // let с явным типом
const d: int = 4;   // константа
svi int lor e = 5;  // старая форма объявления, работает так же
a = a + b;
a += c;             // составные: += -= *= /= %=
a++;
print(a + d + e);
```
```text
16
```

Имена видны в своём блоке `{ }` и во вложенных. Внутренний блок может объявить
то же имя заново (затенение). Использовать переменную до присваивания нельзя.

```sc-error
int x = 1;
int x = 2;
```
```text
повторное объявление 'x'
```

## 4. Операторы и политика целых

Арифметика `+ - * / % **`, целочисленное деление с округлением вниз `//`,
побитовые `& | ^ ~ << >>`, сравнения `< > <= >= == !=`, логические `&& || !`
(с коротким замыканием), тернарный `условие ? a : b`.
`-2 ** 2` равно `-(2 ** 2)`.

```sc
print(7 / 2);
print(7 % 3);
print(2 ** 10);
print(-2 ** 2);
print(17 // 5);
print(6 & 3);
print(1 << 4);
int v = 4;
print(v > 3 ? 10 : 20);
```
```text
3
1
1024
-4
3
2
16
10
```

**Значение молча не портится.** Для целых:
- переполнение `+ - * **`, унарного минуса, `MIN / -1` — ошибка выполнения
  `integer overflow`;
- деление и остаток на ноль — `division by zero`;
- сдвиг на число вне `0..ширина-1` — `shift amount out of range`;
- если такое видно из констант, это ошибка компиляции;
- запись результата в узкий тип (`u8 x; x += 1;`) проверяет диапазон.

```sc-error
print(2147483647 + 1);
```
```text
переполнение: значение константного выражения 2147483648 не помещается в тип 'int/i32'
```

```sc-error
int a = 5;
print(a / 0);
```
```text
деление на ноль
```

Арифметика над `i8`/`u8`/`i16`/`u16`/`char` выполняется в `i32`.

### Преобразования

Неявно разрешено только то, что не теряет значение: расширение целого той же
знаковости, беззнаковое → более широкое знаковое, `f32` → `f64`, любое целое →
`f64`, целое до 16 бит → `f32`. Константа, которая точно помещается в тип,
тоже разрешена (`u8 b = 200;`). Остальное требует явного приведения `(T) x`.
Явное приведение проверяет диапазон: константа вне `T` — ошибка компиляции,
значение во время выполнения — `value out of range for type 'T'`.

```sc
i64 big = 5000000000;
int small = 7;
i64 wide = small;
f64 f = 3.75;
print((int) f);
print(wide);
print((i64) big + 1);
u8 b = 200;
print(b);
```
```text
3
7
5000000001
200
```

```sc-error
i64 a = 1;
int b = a;
```
```text
нужно явное приведение
```

## 5. Условия и циклы

```sc
int x = 3;
if (x == 1) {
    print(1);
} else if (x == 3) {
    print(3);
} else {
    print(0);
}
int n = 0;
while (n < 2) { n += 1; }
print(n);
for i in 0..3 { print(i); }
for j in 1..=2 { print(j); }
svi int[] lor values = [5, 6];
for value in values { print(value); }
cert ceh (2) { print(9); }
loop {
    n += 1;
    if (n == 4) { break; }
    if (n == 3) { continue; }
}
print(n);
```
```text
3
2
0
1
2
1
2
5
6
9
9
4
```

`for i in a..b` — от `a` до `b - 1`, `a..=b` — включительно. `cert ceh (n)`
повторяет блок `n` раз. `loop` — бесконечный цикл, выход через `break` или `return`.
Условие — `bool` или целое (ноль — ложь). Код после `return`/`break`/`continue`
в том же блоке — ошибка компиляции.

## 6. Функции

```sc
fn int square(int x) { return x * x; }
fn void show(int x) { print(x); }
fn bool even(int n);                 // объявление без тела
fn bool odd(int n) { if (n == 0) { return false; } return even(n - 1); }
fn bool even(int n) { if (n == 0) { return true; } return odd(n - 1); }
show(square(5));
print(even(10));
```
```text
25
1
```

Функцию можно вызвать до её определения. Объявление без тела должно совпадать
с определением по типам. Функция с результатом должна возвращать значение на
всех путях (бесконечный `loop` без `break` тоже считается). Вложенные функции,
перегрузка и имена встроенных функций (`max`, `sqrt` …) как имена своих функций
запрещены. Аргументы разделяются запятыми.

## 7. Структуры

```sc
tip Inner { int x = 0; }
tip Pair {
    int a = 1;
    tip Inner inner;
}
fn int sum(tip Pair p) { p.a = 100; return p.a + p.inner.x; }
svi tip Pair lor value = { a = 2; inner = { x = 0; }; };
value.inner.x = 5;
value.a += 1;
print(sum(value));
print(value.a);
```
```text
105
3
```

`tip Имя { поля }` объявляет структуру; поля могут иметь значения по умолчанию.
Экземпляр: `svi tip Имя lor x;` или с инициализатором `{ поле = значение; }`.
В функцию структура передаётся копией. Возвращать структуру из функции пока
нельзя. Рекурсивная структура (поле своего же типа) запрещена.

## 8. Массивы

Статический массив имеет фиксированную длину; индекс проверяется
(константный — при компиляции, остальные — при выполнении).

```sc
svi int[] lor a = [1, 2, 3];
a[0] = 10;
a[1] += 5;
print(a[0] + a[1] + a[2]);
```
```text
20
```

Динамический массив создаётся `nw T[n]`: длина `n`, элементы равны нулю.
Методы: `push(x)`, `pop()` (возвращает элемент, у пустого — 0), `resize(n)`,
`len()`, `cap()`.

```sc
ptr v = nw int[2];
v[0] = 4;
v.push(7);
print(v.len());
print(v.pop());
print(v[0]);
drop v;
```
```text
3
7
4
```

```sc-error
ptr v = nw int[2];
print(v[0]);
fn int g(ptr p) { return 1; }
print(g(v));
```
```text
пока нельзя передать в функцию
```

## 9. Указатели и `null`

`&x` — адрес переменной, `*p` — значение по адресу, `null` — пустой указатель
(допустим только для `ptr`). Разыменование `null` — ошибка выполнения
`null pointer dereference`. Указатели сравниваются только через `==` и `!=`.

```sc
int x = 5;
ptr p = &x;
*p = 9;
print(x);
ptr q = null;
if (q == null) { print(1); }
```
```text
9
1
```

```sc-error
int a = null;
```
```text
null и указатели допустимы только для типа ptr
```

## 10. `defer` и `drop`

`defer операция;` выполняет операцию при выходе из текущего блока, в обратном
порядке. При `return` сначала вычисляется значение, затем выполняются `defer`.
Внутри `defer` нельзя объявлять переменные и делать переходы.

`drop x;` освобождает динамический массив или закрывает файл. После `drop`
имя использовать нельзя, повторный `drop` — ошибка компиляции, как и `drop`
внешней переменной внутри цикла или функции.

```sc
fn int f(int x) {
    ptr v = nw int[2];
    defer drop v;
    defer print(1);
    v[0] = x;
    return v[0] + 1;
}
print(f(4));
```
```text
1
5
```

```sc-error
ptr v = nw int[2];
drop v;
print(v[0]);
```
```text
'v' используется после drop (строка 2)
```

`del p;` освобождает память по указателю без проверок (ручной режим).

## 11. Строки

```sc
string s = "hello";
print(s);
print(ar(s));
print(ser(s, "hello"));
ptr r = rep("a-b", "-", "+");
print(r);
print(str(42));
```
```text
hello
5
1
a+b
42
```

`ar(s)` — длина строки, `ser(s, t)` — равны ли строки,
`rep(s, a, b)` — копия `s` с заменой `a` на `b`, `str(x)` — число в строку.
Сложение строк `+` и сравнение через `==` пока не поддерживаются (для равенства — `ser`).

## 12. Ввод

`vd("подсказка")` читает число, `vv_s("подсказка")` — строку.

```sc
int n = vd("");
string name = vv_s("");
print(n * 2);
print(name);
```
```stdin
21
SC
```
```text
42
SC
```

## 13. Файлы

`atk(путь, режим)` открывает файл (`"w"`, `"r"`, `"a"`; не открылся — ошибка
выполнения), `zap(f, строка)` пишет, `pro(f)` читает строку, `zak(f)` или
`drop f` закрывает.

```sc
file out = atk("spec-file.txt", "w");
zap(out, "строка");
drop out;
file inp = atk("spec-file.txt", "r");
print(pro(inp));
zak(inp);
```
```text
строка
```

## 14. Импорт

`imp "путь.svx";` подставляет другой файл (путь относительно текущего).
Циклические импорты и отсутствующие файлы — ошибка. Пространств имён нет.
Стандартная библиотека: `stdlib/math/math.svx` (`math_abs`, `math_min`,
`math_max`, `math_is_even`).

## 15. Встроенные функции

`sqrt`, `abs`, `pow`, `max(a, b)`, `min(a, b)`, `flo` (вниз), `cel` (вверх),
`ron` (округление), `ran()` (случайное целое), `ar`, `ser`, `rep`, `str`.

```sc
print(max(3, 7));
print(min(3, 7));
print(abs(-4));
print(flo(2.7));
print(cel(2.1));
print(ron(2.5));
print(sqrt(16.0));
```
```text
7
3
4
2.000000
3.000000
3.000000
4.000000
```

## 16. Удалённые слова

У каждого действия одно слово. Старые синонимы удалены; компилятор сообщает
позицию и подсказывает новое слово.

| Было | Пишите |
|---|---|
| `fucn` | `fn` |
| `rev` | `return` |
| `slov` | `print` |
| `eles` / `sele` | `if` / `else` |
| `brk` / `cont` | `break` / `continue` |
| `rox` / `rox64` | `int` / `long` |
| `dor` | `float` |
| `cos` | `string` |
| `bue` | `bool` |
| `chr` | `char` |
| `cop f(x)` | `f(x)` |
| `cert usy (c)` | `while (c)` |

```sc-error
slov(1);
```
```text
слово 'slov' удалено: пишите 'print'
```

## 17. Известные ограничения

- Нет обобщённых типов, перечислений, `Option`/`Result`, сопоставления с образцом,
  замыканий, интерфейсов, пространств имён, многопоточности, FFI.
- Структуры нельзя возвращать из функций; динамические массивы нельзя передавать
  в функции и возвращать.
- Строки из `str()`, ввода и `rep` пока не освобождаются (утечка, не порча памяти).
- Сырой `ptr` не знает длину: индекс `p[i]` проверяется только на `null`.
- Модель памяти (автоматическое освобождение и проверки владения) ещё не сделана;
  `del` — ручной режим без проверок.
- Строки: нет `+`, `==`, работы с Unicode.
